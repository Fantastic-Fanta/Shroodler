### Frontend / API map

- Marketing site is AEM. Ordering SPA assets: `orderweb-cdn.chipotle.com` (loaded by in-scope www).
- Public APIM keys live in HTML meta (`servicesconfig`, `rest`, `mmd`) and Vue env (`gatewaySubscriptionKey`). These are browser keys; program excludes public keys — impact is only what they unlock.
- Catering SPA uses a **different** APIM key and base `https://services.chipotle.com/cateringorder` (+ `/v1`).
- Auth is `Authorization: Bearer` JWT, not cookies. Guest checkout auto-registers `uuid@chipotle.com` via `POST /auth/v2/customer/register` (`createAutogeneratedUser`). Do not curl-register accounts.
- Prod build never sends `x-chipotle-bypass` (`_w()` is `return false`). Header did **not** bypass JWT or Kasada.
- CORS on APIs: allowlist `https://www.chipotle.com` / `https://catering.chipotle.com` + credentials. Evil Origin gets no ACAO.

### What worked unauth (intended / weak)

- `GET /epops/v2/681` → `[]`.

### Auth / bot gate

- Customer, cart, promo, wallet, catering `/order/*` and `/customer`: **401 Bearer** or **Kasada 429** (`x-kpsdk-*`). Stop hammering those from curl (rate-limit tests OOS).
- Guest cart `POST /order/v3/cart/online` without JWT → 401.
